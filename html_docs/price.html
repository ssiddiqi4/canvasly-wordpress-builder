Build pages visually with Canvasly

Canvasly is a visual page builder for WordPress. You design a page on a canvas, then publish it the usual WordPress way. Canvasly Pro adds theme parts, shop units, popups, forms logging, payments, and more, and it only runs when Canvasly is active.

Updated September 23, 2026. Covers Canvasly 0.12.76 and Canvasly Pro 0.6.3.

Canvasly Lite vs Canvasly Pro

Canvasly Lite is the free page builder. Canvasly Pro is a second plugin that adds theme, shop, payments, and the rest of the Pro modules. Every Pro plan unlocks the same features. The plans differ by site count. Pro loads only when Lite is active and at least version 0.12.73.
