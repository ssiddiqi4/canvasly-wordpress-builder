Canvasly documentation

Canvasly is a visual page builder for WordPress. Design a page on a canvas, then publish it in WordPress. Covers install, settings, units, shortcodes, AI and MCP.

Updated September 23, 2026. Covers Canvasly 0.12.76 and Canvasly Pro 0.6.3.

What you can do

  • Open a page or post and choose Edit with Canvasly, or use the same link in the WordPress admin bar.
  • Drag units such as Heading, Image, Button, Container, and Grid onto the page.
  • Switch the canvas between desktop, tablet, and mobile. Extra sizes can be turned on under Design System.
  • Save reusable templates, then place them with a shortcode, a WordPress block, a Canvasly Template unit, or a sidebar widget.
  • With Canvasly Pro, design a header and footer, popups, shop layouts (when WooCommerce is installed), and payment buttons.

These pages describe Canvasly 0.12.76 and Canvasly Pro 0.6.3, as named in the plugin files. WordPress 6.9 or newer and PHP 7.4 or newer are required. The readme lists testing through WordPress 7.1.

Words used in Canvasly

Unit
A piece you place on the canvas: a heading, a button, a container, a grid, and so on. The left panel is the unit library.
Container
A box that holds other units. It cannot be turned off in Units Manager.
Template
A saved Canvasly layout. Saved templates live under the Canvasly menu and can be embedded on other pages.
Design System
Site-wide colors, fonts, content width, and the widths used for phone, tablet, and larger screens.
