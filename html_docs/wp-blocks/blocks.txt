<!-- wp:heading {"level": 1} -->
<h1 class="wp-block-heading">Canvasly units</h1>
<!-- /wp:heading -->

<!-- wp:paragraph {"className": "lede"} -->
<p class="lede">Units are the pieces you drag from the left library onto the canvas. Select a unit to edit it in the right panel. That panel uses Content, Style, and Advanced. Pro units appear in the same library when Canvasly Pro is active. Shop units appear only when WooCommerce is active.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className": "meta"} -->
<p class="meta">Updated <time datetime="2026-09-22">September 22, 2026</time>. Covers Canvasly 0.12.76 and Canvasly Pro 0.6.3.</p>
<!-- /wp:paragraph -->

<!-- wp:html -->
<figure>
      <img src="assets/editor-layout.svg" alt="Editor sketch with the unit library on the left, the page canvas in the center, and Content, Style, and Advanced tabs on the right." width="880" height="420" decoding="async" fetchpriority="high">
      <figcaption>Pick a unit on the left, drop it on the canvas, then change it on the right.</figcaption>
    </figure>
<!-- /wp:html -->

<!-- wp:heading {"level": 2, "anchor": "how-to-add"} -->
<h2 class="wp-block-heading" id="how-to-add">Add a unit</h2>
<!-- /wp:heading -->

<!-- wp:list {"ordered":true} -->
<ol class="wp-block-list">
<!-- wp:list-item -->
<li>Open the page with Edit with Canvasly.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li>In the left panel, search or filter by category and click or drag a unit.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li>Drop it into a Container or a Grid, or onto the page.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li>Use the right panel to change the text, image, link, or layout.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li>Save, then publish or update the page in WordPress.</li>
<!-- /wp:list-item -->
</ol>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>Right-click a unit in the library to add or remove it from Favorites. Container cannot be disabled in Units Manager. Other units can be hidden there.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level": 2, "anchor": "grid"} -->
<h2 class="wp-block-heading" id="grid">Grid</h2>
<!-- /wp:heading -->

<!-- wp:html -->
<figure>
        <img src="assets/grid.svg" alt="A grid sketch with three columns. The bottom-left cell spans two columns. A side panel reads Placement, Column 1, Row 2, 2 by 1, and notes that dragging an edge resizes and neighboring columns share width." width="880" height="260" decoding="async" loading="lazy">
        <figcaption>Grid places children in rows and columns. A child can span more than one cell.</figcaption>
      </figure>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>The Grid unit is a layout that holds other units. Its controls include columns, rows, grid template columns, grid template rows, column gap, row gap, auto flow, align, justify, minimum column and row sizes, auto columns and rows, outline, width, and dense auto-flow. The editor draws a placement grid so you can set column, row, and span. Dragging the left, right, top, or bottom edge resizes the unit, and neighboring columns share the width. A size tip shows while you drag. The Features setting &#8220;Grid container&#8221; is active by default and covers the same kind of layout on a Container.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Usage: add Grid from the layout category, then drop Heading, Image, or Button into the cells. Select a child to set where it sits.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level": 2, "anchor": "context-menu"} -->
<h2 class="wp-block-heading" id="context-menu">Right-click menu</h2>
<!-- /wp:heading -->

<!-- wp:html -->
<figure>
        <img src="assets/context-menu.svg" alt="A white menu listing Edit Heading, Duplicate, Copy, Paste, Copy Style, Paste style, Reset style, Save as Template, and Delete." width="420" height="360" decoding="async" loading="lazy">
        <figcaption>Right-click a unit on the canvas for these actions. Shortcuts can be changed in the editor.</figcaption>
      </figure>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>On a unit, the menu offers Edit, Duplicate, Copy, Paste, Copy Style, Paste style, and Reset style. Tabs, Accordion, and Toggle also offer Convert to nested. Container and Grid offer Add New Container and Save as Template. Any unit can be saved as a component. Structure opens the navigator. Delete removes the unit.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>On empty canvas, the menu offers Paste, Paste All Content, Add New Container, Copy All Content, Delete All Content, and Structure. Copy and paste are kept in the browser so they work across pages and tabs.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level": 2, "anchor": "wordpress-block"} -->
<h2 class="wp-block-heading" id="wordpress-block">WordPress block: Canvasly Template</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>This is the one WordPress block the plugin registers. Its name in the editor is Canvasly Lite Template, in the Canvasly category. It inserts a saved Canvasly template. It still shows in the normal WordPress editor, where the rest of Canvasly does not load.</p>
<!-- /wp:paragraph -->

<!-- wp:html -->
<table>
        <thead><tr><th>Setting</th><th>Default</th><th>What it does</th></tr></thead>
        <tbody>
          <tr><td>Template id</td><td>0</td><td>Which saved template to show. 0 means none is chosen.</td></tr>
        </tbody>
      </table>
<!-- /wp:html -->

<!-- wp:paragraph -->
<p>The block can be wide or full width, and it supports an HTML anchor and a CSS class. Usage: in the WordPress block editor, add Canvasly Template, then pick the saved template.</p>
<!-- /wp:paragraph -->

<h2 class="wp-block-heading" id="other-surfaces">Other things visitors and editors see</h2>
<!-- /wp:heading -->

<!-- wp:list -->
<ul class="wp-block-list">
<!-- wp:list-item -->
<li><strong>Popups.</strong> A Popup template from Theme Builder is hidden in the footer and can open on load, scroll, click, exit, or inactivity. How often it shows uses a cookie set by the site. A link action can open a popup. A Canvasly form inside a popup still works.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li><strong>Editor notes.</strong> With Pro, a logged-in person who can edit the page can leave a note on a unit. Notes are not public comments and are not printed on the site.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li><strong>Saved templates.</strong> Stored as private content under Canvasly, with categories. Types include Page, Section, Container, Header, Footer, Single, Archive, Loop Item, and Floating Button. Pro adds the Theme Builder types.</li>
<!-- /wp:list-item -->
<!-- wp:list-item -->
<li><strong>Maintenance.</strong> When maintenance or coming soon is on, visitors see the chosen template. Excluded roles still see the live site.</li>
<!-- /wp:list-item -->
</ul>
